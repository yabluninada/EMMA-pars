Файл from_midi - чистый перевод из мидика в формат сценария без распределения скоростей и направлений смычка (интерфейс - вайб)

algo - алгоритм распределения, смотри последнюю из представленных функций, она актуальна, остальные лежат на всякий случай
raspr - обертка для algo чтобы он брал не массивы чисел, а формат нашего сценария, вайб
visual - вайб-функция для algo чтобы красиво вывести что оно там распределило, по умолчанию отображение включено, чтобы отключить, переключи флаг в algo 
smych - весьма тупой старый алгоритм, который сложно назвать алгоритмом, просто заполняет смычки полностью, подсвечивая красным всё что не получилось распределить. Там в окошке есть функция reverse, удобная при редактировании сценариев (типовые подфункции и интерфейс - вайб)
umoz - окошко для перевода темпа (сохраняет положения смычка компенсируя изменения длительностей скоростью) и проверки валидности сценария

> [!TIP]
> Мини-коды для ручного редактирования сценариев можно найти в [диалоге с нейросетью](https://chat.deepseek.com/share/b8c4bjycqm72eavdb1).
